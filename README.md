# homebrew-katana

Homebrew tap for [KatanA Desktop](https://github.com/HiroyukiFuruno/katana) — a lightweight Markdown viewer for macOS.

## Installation

```sh
brew tap HiroyukiFuruno/katana
brew install --cask katana-desktop
```

## Update

```sh
brew upgrade --cask katana-desktop
```

## Uninstall

```sh
brew uninstall --cask katana-desktop
```
