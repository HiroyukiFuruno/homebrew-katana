# homebrew-katana

Homebrew tap for [KatanA Desktop](https://github.com/HiroyukiFuruno/katanA) and [katana-markdown-linter](https://github.com/HiroyukiFuruno/katana-markdown-linter).

## Tap

```sh
brew tap HiroyukiFuruno/katana
```

## KatanA Desktop

```sh
brew install --cask katana-desktop
```

Update:

```sh
brew upgrade --cask katana-desktop
```

Uninstall:

```sh
brew uninstall --cask katana-desktop
```

## kml

Install the latest `kml` formula:

```sh
brew install kml
```

Update:

```sh
brew upgrade kml
```

Install a pinned formula:

```sh
brew install kml@0.17.4
```

Versioned formulae are keg-only and are available from `kml@0.17.1` onward for releases also published to npm or PyPI.
`kml@0.17.2` is intentionally not included because that version was not published to npm or PyPI.

Uninstall:

```sh
brew uninstall kml
```
